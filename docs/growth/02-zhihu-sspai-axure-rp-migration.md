## 一、免装 Axure：把 `.rp` 直接拖进工作台就能拆解

打开 ProtoFlow AI 桌面端（安装包沿用 `Alex` 应用名，免登录开箱即用），在启动页点击「导入 Axure 原型」或直接把 **Axure RP 9 / RP 11 的 `.rp` 文件** 拖进去：

- **纯本机 Worker 离线解析**：不调用外部云端接口，不需要电脑上安装 Axure。
- **还原哪些真实结构？**
  - 多级站点目录与页面树；
  - 分组（包括隐藏组）与绝对定位坐标；
  - 静态表格的每一个单元格；
  - 母版（Master）实例的子控件作用域隔离；
  - 动态面板（DynamicPanel）的多个状态；
  - 无条件交互中的「当前窗口跨页跳转」「即时显隐」和「切换动态面板状态」。
- **遇到不支持的特性怎么办？** 像中继器（Repeater）、复杂条件分支等会老老实实列在每页的导入备注与转换限制清单里，不悄悄吞掉、不乱报成功。

导完之后，你已经可以直接在画布里可视化修改文本、按钮、静态表格单元格，保存成一个开放可读的本地 `.pflow` 工程（还能解包成 Git 友好的目录树）。

## 二、更进一步：把静态 `.rp` 原型「变活」成共享 ER 表驱动的交互原型

仅仅导入成静态画板还不够，B 端原型真正省力的是**让表头和交互真正接上物理数据表**。在工作台左侧打开 **「项目 AI」**，选择迁移范围（**单页 / 目录含子目录 / 全工程**）：

1. **先只读分析盘点**：AI 先不改你的页面，而是帮你盘点出页面里有哪些筛选框、表头字段和待确认的业务关系；
2. **表头 ↔ 数据库字段逐项映射核对**：AI 自动把散落在页面上的标签和输入框（`nearbyLabel`）收拢成标准的 `QueryForm` 查询栏，并让你核对**原型静态表格表头 → 真实物理 ER 表字段**的映射关系（静态表格里的示例假数据不会污染真实预览数据集）；
3. **同目录保留原页 + 生成优化流式页**：确认后，原汁原味的 RP 页面会**完整保留在原目录里对照**，同时生成绑定共享 ER 物理表的 `QueryForm + Table + Descriptions` 交互页面——点击行详情跳转（`navigate(targetPageId, 'row')`）时，`Descriptions` 详情页能自动带入对应行的真实数据。
4. **透明的核对清单**：每次转换都会列出 **已转换（Converted）/ 保留（Retained）/ 待处理（Pending）** 三份清单，改了哪些、留了哪些一目了然。

## 三、升级完之后，怎么交给团队评审和研发落地？

1. **给同事 / 客户在线体验**：可以用自带的 3 步 Docker Compose 配置文件在自己内网或服务器搭一个评审中心，一键生成带密码保护、可随时更新/撤回的 `/p/{id}` 交互链接；或者直接本地导出零依赖的交互 HTML 发出去。
2. **直接交给 Claude Code / Cursor 写代码**：一旦 `.rp` 升维成了绑定 ER 物理表的工程，你的开发团队就可以通过内置的 **MCP（Model Context Protocol）服务**，让 IDE 里的 AI 直接读取标准 PostgreSQL/MySQL DDL、页面 TSX 和贴在按钮上的需求便签规则，不用再去翻几年前过时的静态 Axure HTML 切图。
