About Alex (ProtoFlow AI)

Alex (ProtoFlow AI) is an Apache-2.0 open-source desktop prototyping and relational data modeling workbench built to bridge product requirements, interactive validation, and AI-assisted software delivery.

Why We Built Alex

Product managers, business analysts, solution architects, and engineering teams routinely get stuck between static wireframes (where forms do not submit real rows and pages cannot share state) and one-shot AI HTML generators (which guess ambiguous business rules blindly, hardcode disconnected mock data per page, and break layouts whenever a field changes).

Alex resolves both gaps by keeping one shared physical ER schema, a bidirectional TSX AST canvas, component-level requirement sticky notes, and real cross-screen data flow inside a single local-first .pflow workspace.

Core Open-Source Architecture

  • Desktop Workbench (Electron + React + TypeScript): Runs locally on macOS, Windows, and Linux with zero mandatory account login.
  • Clarify-First Project AI (NousResearch Hermes): Asks clarifying questions on business boundaries and proposes sitemaps + physical ER schemas before generating screens.
  • Native Axure .rp Binary Parser: Parses Axure RP 9 and RP 11 files offline without installing Axure, preserving original pages alongside table-bound flow conversions.
  • Model Context Protocol (@protoflow-ai/mcp): Exposes 18 contract-validated authoring tools for live desktop co-design and 6 read-only specification tools for zero-install engineering handoff.
  • Self-Hosted Publishing Stack (Go + PostgreSQL + Nginx): Optional 3-command Docker Compose server for sharing password-protected, expiring /p/{id} team review links.
