Alex (ProtoFlow AI) 在线交互原型演示 — CRM 合同与回款开票业财系统

这是一个免下载、免登录的浏览器可运行业务原型沙盒，基于 Apache-2.0 开源工作台 Alex (ProtoFlow AI) 构建。启用 JavaScript 后，页面会自动加载实时交互工作台与持久化沙盒状态。

这个在线示例包含哪些可交互页面与共享数据表

当前示例工程完整演示了多页面、跨终端共享物理 ER 数据表的实时联动效果，包含 4 个 PC 中后台页面、2 个 iPhone 移动端视口页面、5 张共享物理数据表与 9 条组件级需求便签：

  • PC 管理端页面：业财经营与回款看板、企业客户与商机台账、销售合同审批与履约台账、回款核销与开票工作台。
  • iPhone 移动端视口页：移动审批与回款催办、客户拜访与移动开票。
  • 共享物理 ER 数据表：t_crm_customers、t_crm_contracts、t_crm_payment_plans、t_crm_invoices、t_crm_monthly_revenue。

如何开始体验与完整桌面版能力

在浏览器中可直接切换左侧目录与 PC/移动端视口，在表单和台账中增删改查记录并查看多页面与图表联动，同时点击查看挂在控件上的黄色需求便签。 下载完整桌面端后，还可使用先追问澄清再规划蓝图的 Hermes AI、本地免装 Axure .rp 二进制导入、双向 AST 画布精修、18 个双向 MCP 协同工具，以及 3 步 Docker Compose 团队私有化发布服务。
