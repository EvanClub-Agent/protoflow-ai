Alex (ProtoFlow AI) 在线交互原型演示 — 星链设备售后维保与备件履约平台

这是一个免下载、免登录的浏览器可运行业务原型沙盒，基于 Apache-2.0 开源工作台 Alex (ProtoFlow AI) 构建。启用 JavaScript 后，页面会自动加载实时交互工作台与持久化沙盒状态。

这个在线示例包含哪些可交互页面与共享数据表

当前示例工程完整演示了无弹窗主从工作台、跨端共享物理 ER 表、外键 RESTRICT / CASCADE 防误删闭环与 UI Stack 五态容错能力，包含 3 个 PC 中后台页面、1 个 iPhone 掌上现场端页面、3 张共享物理数据表与 8 条组件级需求便签：

  • PC 调度管理端页面：维保运营数据看板、维保工单主从工作台、履约流转看板与排期日历。
  • iPhone 移动端视口页：工程师现场接单与领料端（含触控状态看板、周日程流与随车领料半屏抽屉）。
  • 共享物理 ER 数据表：srv_tickets（维保工单主表）、srv_part_usages（备件领用明细表 · RESTRICT）、srv_ticket_logs（现场跟进日志表 · CASCADE）。

如何开始体验与完整桌面版能力

在浏览器中可直接切换左侧菜单、顶部 UI Stack 五态（理想态/空数据/加载中/极值态/异常态）与中英双语，体验无弹窗主从切行、跨字段日期与库存上限防错校验、5 秒可撤销级联归档以及黄色需求便签。 下载完整桌面端后，还可使用先追问澄清再规划蓝图的 Hermes AI、本地免装 Axure .rp 二进制导入、双向 AST 画布精修、18 个双向 MCP 协同工具，以及 3 步 Docker Compose 团队私有化发布服务。
