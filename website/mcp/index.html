Alex (ProtoFlow AI) MCP Server & API

Connect AI coding agents directly to Alex prototypes using the Model Context Protocol (MCP) — for live bidirectional canvas authoring or zero-install engineering specification handoff.

1. Remote Zero-Install Spec API (POST /api/v1/mcp/<shareId>)

After publishing any prototype to a self-hosted /p/{id} URL, engineers paste one Streamable HTTP configuration block into their IDE to query database schemas, PostgreSQL/MySQL DDL, page TSX, and component sticky specs without installing Alex Desktop locally: 

{
  "mcpServers": {
    "protoflow": {
      "url": "https://protoflow.example.com/api/v1/mcp/<shareId>"
    }
  }
}

6 Read-Only Specification Tools

  • protoflow_get_project_overview — Project modules, sitemap tree, desktop/mobile pages, and table inventory.
  • protoflow_get_database_schema — Normalized ER tables, foreign keys, unique constraints, sample rows, and PostgreSQL/MySQL DDL.
  • protoflow_get_page_spec — Component hierarchy, TSX source, table bindings, actions, and pinned sticky-note constraints.
  • protoflow_get_docs_and_flows — Project Markdown notes and Mermaid workflow diagrams.
  • protoflow_search_spec — Full-text search across pages, fields, notes, and components.
  • protoflow_get_implementation_checklist — Ordered implementation checklist derived from schemas, flows, and sticky notes.

2. Bidirectional Live Canvas Co-Design (18 Authoring Tools)

Enable MCP → Local → Bidirectional design in Alex Desktop to expose the authenticated loopback bridge (live.json) with sequential expectedRevision concurrency guards and multi-step Cmd/Ctrl+Z undo:

  • Create or reorganize sitemap folders and pages (protoflow_manage_sitemap).
  • Design normalized ER tables with foreign keys and composite unique constraints (protoflow_upsert_db_tables) and seed coherent sample rows (protoflow_manage_table_rows).
  • Write or patch desktop (<Page>) and mobile (<MobilePage>) trees (protoflow_write_page, protoflow_edit_page_block), attach sticky-note rules (protoflow_manage_sticky_notes), author docs/Mermaid flows, and run closed-loop audits (protoflow_audit_project).
  • Capture offscreen high-DPI PNG previews via protoflow_capture_preview after ECharts and Freeform first paint to visually inspect layout quality.

Full CLI & stdio documentation is available in packages/protoflow-mcp/README.md.
